高级设置
这个助手能做什么、不能做什么

能做：回答问题；看照片和截图（药盒、化验单、说明书、路牌、外文菜单）；读 PDF、Word 和文本文件；写东西、翻译、算账。

不能做：它碰不到你的手机相册和通讯录，也不能替你打电话、发消息、付款。它只认识你发给它的内容。

照片会不会被存下来？照片只在你按下发送时传给 DeepSeek 用于回答，这个网页不会保存它们；聊天文字存在你自己手机里。

怎么获取 API Key？
  1. 打开 platform.deepseek.com，注册并登录。
  2. 进入「API keys」，点「创建 API key」。
  3. 复制 sk- 开头的那串，粘贴到上面的输入框。

余额和用量都在同一个平台查看。建议单独建一个 Key 专供手机使用，丢了可以直接删掉。
