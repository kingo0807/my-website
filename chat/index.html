怎么获取 API Key？
  1. 在手机或电脑打开 platform.deepseek.com，注册并登录。
  2. 进入「API keys」页面，点「创建 API key」。
  3. 复制 sk- 开头的那串字符，粘贴到上面的输入框并保存。

余额和用量都在同一个平台查看。建议专门创建一个只给手机用的 Key，万一手机丢了可以在平台上直接删掉它。
